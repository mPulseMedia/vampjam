A

Three things from Twilio

twilio is the company that actually sends the text message. you need three things off their site: an account SID, an auth token, and a phone number to send from. nothing here touches vampsf yet.

  1. Go to console.twilio.com and sign in. You want the page headed Get started with Twilio, with a dark menu down the left: Phone Numbers, Messaging, Voice. Twilio runs two consoles. If you land on a blue Let's get building instead, that is the newer one — click Twilio Home top left to come back here. Both work; this one is easier, because it keeps both of the things you need on a single card.
  2. Scroll to the bottom of that dashboard. Bottom left there is a card headed Account Info. Copy the Account SID — the copy icon is at the right of the box. Paste it into Notes for a minute. A long string starting AC. Not secret, but it is half of a pair. drawn from twilio's own screen, not yours
  3. Directly under it on the same card: Auth Token, shown as dots. Use its copy icon, or click Show first if you want to see it. This one is a password — Twilio says so right underneath. It goes into one box on Cloudflare in step D3 and nowhere else. Do not paste it into a chat, including to me. drawn from twilio's own screen, not yours
  4. In the left menu: Phone Numbers → Manage → Active numbers. Copy the number in the form +14155551212 — keep the +1. Its capabilities must include SMS. Voice alone will not do. If this is still a trial number, it can only text numbers you have verified with Twilio. That is enough to test on your own phone, and it is where the whitelist will stop for everyone else until you upgrade. If the list is empty: Buy a number, tick SMS, search, buy — about $1.15 a month plus roughly a cent per text. drawn from twilio's own screen, not yours
B

Make the worker

a "worker" is a small program of yours that lives on cloudflare — the same place your audio and your session list already live. this one checks who is on your list and asks twilio to send the text. you already have vampjam-upload, vampjam-sync and page-agent-keeper there. this is another of the same kind.

  1. dash.cloudflare.com, sign in. Left menu: Compute → Workers & Pages. Your own workers listed: page-agent-keeper, vampjam-upload, vampjam-sync. Right of the heading, a blue Create application. drawn from cloudflare's own screen, not yours
  2. Click Create application. A box comes up headed Make something new with five choices. Take Start with Hello World! — the middle one. Not GitHub, not a template, not upload. Those all want a repository or files; you are going to paste the program in by hand in part C. Ignore Continue to Pages at the bottom too — that is the old workflow, and it is for websites, not workers. drawn from cloudflare's own screen, not yours
  3. Name it vampjam-auth — exactly that, lower case, with the hyphen. The site looks for that name. Then Deploy. It deploys a do-nothing program that answers "Hello World". That is expected — the real one goes in next. If it says the name is taken, you already made it. Go back to the list, open vampjam-auth, and carry on at C.
C

Paste the real program in

the button below hands you the exact program that is committed to your repo — it is fetched off the site when you tap it, so there is no second copy anywhere to drift out of date. nothing in it needs editing.

  1. Tap the dark line below — it copies itself. About 200 lines. The label turns green and tells you how big it was. Nothing happens, or it says it could not copy? Tap show it under the button and select the text by hand, or open the file on GitHub and use ⌘A ⌘C. All three give you exactly the same thing.
  2. On vampjam-auth: Edit code, top right (sometimes behind a </> icon). Click inside the code, ⌘A to select all, ⌘V to paste over it. Then Deploy. Done when the button settles and there is no red anywhere. drawn from cloudflare's own screen, not yours
  3. Near the top of the worker page is an address ending .workers.dev. The site expects vampjam-auth.crimson-dust-a18d.workers.dev If yours is different, paste it to me — one line for me to change. Do not rename anything.

  2. 
      Your number is +1844…, which makes it toll-free, and a toll-free number cannot
      text anyone in the US until Twilio has verified it. Check it now, before you test:
      Phone Numbers → Manage → Active numbers → your number →
      Regulatory Information. If it is not Approved, use Verify this toll free
      number there.
      Approved is the only status that sends. Not verified, Verification in
      progress and Rejected all mean blocked.
      Twilio blocks these outright rather than quietly dropping them, which is
      the good news: the failure has a name. If a text does not arrive, the error is
      30032 — toll-free number has not been verified. Tell me if you see it and I will show
      it to you on the site rather than leaving it in a log.

      normal local number needs none of this — if waiting is worse than a dollar a month, buy one
