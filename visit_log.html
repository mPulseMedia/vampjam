Play log

Who opened what, and how long they stayed. Nothing in the app shows any of this.
Nobody is asked who they are. Each browser invents a random id for itself and keeps it to itself. It is enough to say four plays were one person rather than four; it is not enough to say which person. No name, no number, no sign-in, no location.

Switch it on — about five minutes
  1. Make the shelf it writes to
    • go to dash.cloudflare.com.
    • left sidebar: Storage & Databases → KV.
    • click Create a namespace.
    • name it exactly vampjam_visit and create it.
  2. Make the worker
    • Workers & Pages → Create → Start with Hello World.
    • name it exactly vampjam-visit — the site already expects that name.
    • deploy it, then Edit code.
  3. Paste the code
    • select everything in the editor and delete it.
    • paste the contents of cloudflare/vampjam_visit_worker.js from the repo.
    • click Deploy.
  4. Join the two together
    • that worker → Settings → Bindings → Add → KV namespace.
    • Variable name: VISIT   KV namespace: vampjam_visit.
    • save, then Deploy once more.
    • come back here and press Refresh.
Until this is done nothing is lost and nothing is broken — the site simply does not count. Plays before the switch-on are not recorded anywhere, so the log starts the day you finish step 4.
The log keeps about a year and then lets the oldest days go.
