Open Voice Memos.

Tap the recording.

Tap Save to Files.

B

Name it before you save it.

Tap the name at the top and type over it.

Date first, then the place, then .m4a.

then type the place.

Tap Save.

The file is in Files under the name you typed.

C

Put it in the bucket.

Tap the vampjam-audio bucket. It opens in a new tab.

If Cloudflare asks you to sign in, sign in. It returns you to the bucket.

Tap Upload.

Tap Choose files, then pick the memo from Files.

A new row in the Objects list, with your filename on it.
