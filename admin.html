Add a new session

From a Voice Memos recording to a live, taggable session page.
Open the vampjam-audio bucket Cloudflare R2 → where the audio lives now
Steps
  1. Record on your iPhone
    Use Voice Memos. It already records iOS-friendly .m4a — no conversion needed anymore.
  2. Let it sync to the Mac
    It appears in Voice Memos on the Mac in a minute or two over iCloud. Open Voice Memos on the Mac to nudge it if it's slow.
  3. Drag it into the R2 bucket
    In Voice Memos on the Mac, drag the recording into the vampjam-audio bucket's drop zone (open it with the button above → Objects). Give it a simple no-spaces name like sound_union_2026_08_14.m4a if you can. The bucket is already public, so nothing else to configure.
  4. Tell Claude
    Message Claude the file name + session date, and send screenshots of any timestamps you want as numbered highlights. Claude builds the session page, points it at the R2 URL, adds the highlights, and publishes.
Why this is the whole flow now: R2 serves reliably to iPhone (unlike the old GitHub releases), and Voice Memos already exports the right format — so no QuickTime conversion and no re-upload roulette. The only step that's yours is the one drag into the bucket; Claude does everything after that.
