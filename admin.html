Add a new session

From a Voice Memos recording to a live, taggable session page.
+ New release on GitHub opens the release page where you upload the audio
Steps
  1. Get it out of Voice Memos
    Open Voice Memos on the Mac and drag the recording onto your Desktop.
  2. Convert in QuickTime
    Open that file in QuickTime Player, then File → Export As → Audio Only. That saves an .m4a (AAC audio) — the format vamp jam plays everywhere, including iPhone.
  3. Upload it as a release
    Use the New release button above. Give it a tag like 2026-08-07_vampjam_su, drag the .m4a into the assets box, and Publish release.
  4. Tell Claude to add it
    Message Claude: “add the newest release to the app.” Claude builds the session page and wires it into the menu.
If audio is silent after upload: that's usually a GitHub 503 on a fresh asset — delete the asset and drag the .m4a back in through the release's edit page, then it serves cleanly.
